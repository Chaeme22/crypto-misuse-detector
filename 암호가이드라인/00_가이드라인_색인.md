# 암호 가이드라인 문서 색인

오픈소스 암호오용 탐지 도구 개발 프로젝트의 **RAG 근거 문서 · 데이터셋 라벨링 기준 · 내부 스터디 교재**로 사용하는 표준/가이드라인 모음.

- **Tier-2 RAG**: 탐지 결과에 인용할 권위 있는 원문 조항 (정상/오용 판정의 *근거*)
- **Secure Baseline**: '안전한 구현 기준' 정의에 사용 (정상 코드 데이터셋 생성 기준)
- **Misuse 기준**: 오용 패턴/CWE 매핑에 사용 (오용 코드 데이터셋 생성 기준)

---

## NIST (국제 표준 · 심각도 분류 근거)

### 1. Transitioning the Use of Cryptographic Algorithms and Key Lengths — SP 800-131A
- 암호 알고리즘·키 길이의 **전이(transition)** 정책. 각 알고리즘이 *승인(Acceptable) / 폐기예정(Deprecated) / 제한사용(Legacy use) / 사용금지(Disallowed)* 중 어느 상태인지 규정.
- 3DES 폐기, SHA-1 서명 금지, RSA/DH 2048비트 이상, 대칭키 112비트 이상 등 구체 기준 명시.
- 본 프로젝트 **탐지 결과 심각도(severity) 분류의 직접 근거** — 탐지된 알고리즘을 이 4단계 승인 상태로 매핑.
- 신규 암호화 vs 기존 데이터 복호화(Legacy)를 구분하는 판정 로직에 활용.
- 매핑 CWE: CWE-327(취약 알고리즘), CWE-326(불충분한 키 길이).

### 2. Recommendation for Key Management — SP 800-57 Part 1
- 키 관리 **일반 지침**. 키 유형·보안강도·암호주기(cryptoperiod)·키 생성/보관/폐기 전 생명주기 규정.
- 보안강도(112/128/192/256비트)별 대칭·비대칭 알고리즘 대응표 제공.
- 키 오용(하드코딩 키, 짧은 키, 재사용, 수명 초과) 판별의 근거 문서.
- 정상 데이터셋의 '올바른 키 관리' 예시 생성 기준으로 사용.
- 매핑 CWE: CWE-321(하드코딩 키), CWE-320(키 관리 오류).

### 3. Recommendation for Block Cipher Modes of Operation — SP 800-38A
- 블록암호 운영 모드 정의: **ECB, CBC, CFB, OFB, CTR**.
- ECB의 동일 평문→동일 암호문 취약성 명시, CBC의 **예측 불가능 IV** 요구사항 규정.
- 모드 오용(ECB 사용, 고정/재사용 IV) 탐지의 직접 근거.
- 기밀성 전용 모드의 한계 → 인증암호(AEAD) 권고 문맥 제공.
- 매핑 CWE: CWE-327(ECB), CWE-329(고정/재사용 IV), CWE-1204(예측가능 IV).

## KISA (국산 암호 · 국내 기준)

### 4. 암호 알고리즘 및 키 길이 이용 안내서 (2018.12) ★핵심
- 보안강도(112~256비트)별 **권고 암호 알고리즘·키 길이·유효기간**을 표로 제시.
- SEED·ARIA·LEA·HIGHT 등 **국산 암호**와 HAS-160·SHA-2, KCDSA·EC-KCDSA 포함.
- 서구 도구(Semgrep/CodeQL)가 놓치는 **국산 암호 커버리지**의 핵심 근거 — 본 프로젝트 차별점.
- 국내 기준 Secure Baseline 정의 및 심각도 판정의 1차 근거.
- 매핑 CWE: CWE-327, CWE-326.

### 5. 암호이용 안내서 (2013)
- 암호 이용 전반의 기초 가이드 — 대칭/공개키/해시/난수 선택 기준 서술.
- 기밀성·무결성·인증 등 보안서비스별 적정 암호기술 대응 정리.
- 초심자 내부 스터디 입문 교재 및 정상 구현 예시 근거로 사용.
- 국내 관점의 '안전한 암호 이용' 서술 → RAG 보조 근거.

### 6. 암호 키 관리 안내서 (2014)
- 키 **생명주기**(생성·분배·저장·폐기) 국내 관리 기준. NIST 800-57의 국내 대응 문서.
- 키 생성 시 난수 요구사항, 키 보관·분리 원칙 서술.
- 하드코딩 키·약한 키 유도·키 재사용 오용 판별 근거.
- 매핑 CWE: CWE-321, CWE-320, CWE-330(취약 난수 기반 키).

### 7. HTML5 암호기술 이용 안내서 (2015)
- 웹/HTML5 환경(Web Crypto API 등) 암호 적용 가이드.
- 브라우저·JavaScript 환경의 암호 오용(약한 알고리즘, 클라이언트 키 노출) 사례 근거.
- JS 대상 코드 스니펫 오용 판별 시 보조 근거로 활용.

### 8. 다양한 보안 프로토콜에서의 SEED 활용 가이드라인 (2008)
- TLS/IPsec 등 프로토콜에서 **SEED** 적용 방식 규정.
- 국산 암호 SEED 정상 사용 예시 데이터 생성 근거.
- 프로토콜 문맥의 국산 암호 정상/오용 판별 보조.

### 9. 사물인터넷(IoT) 환경에서의 암호인증기술 이용 안내서 (2017)
- 경량 환경(IoT) 암호·인증 기술 이용 기준. LEA 등 경량암호 활용 포함.
- 자원 제약 환경의 '약한 암호 오해' vs '적정 경량암호' 구분 근거.
- (부속: `아두이노 소스코드_2017.zip` — 안내서 예제 구현, 정상 구현 샘플 참고용.)

### 10. 양자컴퓨팅 환경에서의 암호기술 이용 안내서 (2017)
- 양자내성암호(PQC) 전환 필요성 및 양자 위협 하 기존 암호 취약성 서술.
- RSA/ECC의 양자 취약성 문맥 — 향후 'quantum-vulnerable' 태그 확장 근거.
- 중장기 로드맵/논문 배경 서술용 참고 문서.

### 11. 패스워드 선택 및 이용 안내서 (2019)
- 안전한 패스워드 생성·저장(솔트·해시·반복) 기준.
- 패스워드 해싱 오용(평문 저장, 솔트 없음, 약한 해시) 판별 근거.
- 매핑 CWE: CWE-759(솔트 없는 해시), CWE-760(예측가능 솔트), CWE-916(불충분한 계산비용 해시), CWE-328(취약 해시).

## CWE ↔ 문서 매핑 요약

| CWE | 오용 유형 | 주 근거 문서 |
|---|---|---|
| CWE-327 | 취약/위험 알고리즘 (DES, MD5, ECB) | NIST 800-131A, 800-38A / KISA 2018 |
| CWE-328 | 취약 해시 (MD5, SHA-1) | NIST 800-131A / KISA 패스워드 안내서 |
| CWE-329 | IV/Nonce 재사용·고정 | NIST 800-38A |
| CWE-330 | 취약 난수(비암호학적 PRNG) | KISA 키 관리 안내서 |
| CWE-321 | 하드코딩 암호키 | NIST 800-57 / KISA 키 관리 안내서 |
| CWE-326 | 불충분한 키 길이 | NIST 800-131A / KISA 2018 |
| CWE-780 | 불안전 패딩 (RSA PKCS#1 v1.5) | NIST 800-131A |
| CWE-759/760/916 | 패스워드 해싱 오용 | KISA 패스워드 안내서 |
